# IPL 2022 Data Analysis

## Overview

This project analyzes the **IPL 2022 dataset** using Python to uncover insights about match outcomes, toss impact, and player performance through data cleaning, aggregation, and visualization.

---

## Objectives

* Evaluate **toss winner vs match winner** impact
* Identify **top bowlers** based on wickets
* Explore match patterns using visualizations

---

## Key Insights

* Toss outcome has a **moderate impact** on match results *(based on analysis)*
* Some teams perform better after winning the toss
* Top-performing bowlers can be identified through aggregated statistics

---

## Tech Stack

* Python
* Numpy & Pandas (data analysis)
* Seaborn & Matplotlib (visualization)
* Plotly / Cufflinks (interactive plots)

---

## Dataset

* `IPL.csv` – contains match-level data (teams, toss winner, match winner, etc.)

---

## Visualizations

* Bar charts (toss impact, top bowlers)
* Scatter plots (variable relationships)
* Count plots (distribution insights)

---

## How to Run

1. Clone the repository
2. Open the Jupyter Notebook
3. Run all cells
